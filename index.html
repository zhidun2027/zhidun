Capabilities

What it does

Six protections working together: your code is encrypted, the entry point is replaced, the runtime is guarded.

DEX

DEX encryption

The original classes.dex is packed, encrypted, and hidden in assets — no plaintext code remains in the APK. Custom stream cipher, a fresh random key per build.

stream cipherrandom dexKey
SO

Native engine

libjiaguo.so is the runtime engine across four ABIs. Decryption, integrity checks, and swapping back the real Application all happen in native code.

arm64-v8aarmeabi-v7ax86_64mips64
RUN

Shell loader

StubApp loads the .so in attachBaseContext, reads cls_key to derive the dexKey, restores the original DEX, and swaps the real entry back via RefInvoke.

StubAppRefInvoke
DBG

Anti-debugging

Detects ptrace via TracerPid in /proc/self/status, and a watchdog thread catches timing drift — it exits on anomaly.

ptracewatchdog
ENV

Environment detection

Flags root, Xposed / Substrate, HTTP proxy, VPN, app-cloning, USB debugging, and developer options.

rootXposedVPN/proxycloning
SIG

Multi-scheme signing

Re-signs with apksig: JAR (v1) plus APK Signature Scheme v2 / v3, covering old and new Android.

v1v2v3
Pipeline

Eight steps per run

From a raw APK to a hardened build — every step verified on a real APK.

01

Decompile

apktool unpacks the APK; extract DEX, resources, manifest.

02 · core

Encrypt DEX

Original DEX encrypted with a random key, written to assets.

03

Build cls_key

dexKey / signa / init_pass metadata, encrypted as a whole.

04 · core

Inject shell

StubApp shell DEX and libjiaguo.so placed into the package.

05

Rewrite Manifest

application entry replaced with the shell's StubApp.

06

Repack

apktool rebuilds to an unsigned APK.

07

Align

zipalign does 4-byte alignment.

08

Re-sign

apksig signs v1 / v2 / v3.

Quick Start

Quick start

A Gradle project on JDK 21. Launch the GUI to pick an APK and keystore and hit start, or drive it from the command line.

Launch the GUI
$ ./gradlew run # or build a single runnable jar $ ./gradlew fatJar $ java -jar build/libs/zhidun-3.3.7-all.jar
Runtime layout
workdir/ ├─ config.dll # shell resource pack └─ tools/ ├─ apktool(.bat) # Win / Linux └─ zipalign(.exe) # sign with your own keystore

※ The tool looks for config.dll and tools/ in the working directory or next to the chosen APK. On Windows use apktool.bat + zipalign.exe; on Linux the extension-less versions.
